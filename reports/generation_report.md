**t05**: как сохранить данные в localStorage браузера

> Можно использовать Web Storage API для хранения данных в браузере. Например, с помощью метода `localStorage.setItem()` [4]. Также можно преобразовать объект в строку JSON с помощью `JSON.stringify()` и затем сохранить его в `localStorage` [4], [5].
